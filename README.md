# Bartolomeu Adorno | Portfólio

Site-portfólio responsivo de Bartolomeu Adorno, estudante de Engenharia de Software e desenvolvedor em início de carreira.

## Tecnologias

- HTML5
- CSS3
- JavaScript
- Node.js
- Java
- React, em estudo

## Funcionalidades

- Layout responsivo para celular, tablet e desktop
- Navegação por seções
- Menu mobile
- Animações de entrada ao rolar a página
- Seções sobre, habilidades, projetos e contato
- Servidor local simples com Node.js

## Como executar

1. Instale o Node.js.
2. Clone ou baixe este repositório.
3. Abra a pasta do projeto no Visual Studio Code.
4. Execute no terminal:

```bash
node server.js
```

5. Abra o endereço local informado no terminal.
